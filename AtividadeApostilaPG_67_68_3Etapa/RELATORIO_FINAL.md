# Relatório final

A atividade das páginas 67 e 68 foi reproduzida em Python com pandas, numpy, matplotlib e seaborn.

Foram implementadas as etapas de preparação dos dados, conversão de datas, cálculo de faturamento, verificação de integridade, tratamento de valores nulos pela média, agrupamentos, ticket médio, produtos mais vendidos, análise mensal e todas as visualizações solicitadas.

Também foram aplicadas estilização global, títulos e rótulos adequados, layout com múltiplos gráficos e exportação dos resultados para arquivos CSV e PNG.

Os dados são fictícios, pois as páginas permitem criar um dataset quando o arquivo `vendas.csv` não é fornecido.
